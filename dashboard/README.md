# job-hunter-agent dashboard

Next.js App Router dashboard for job-hunter-agent's Supabase-backed listing history. See the [root README](../README.md) for the full project overview, setup instructions, and current deploy caveats.

```bash
npm install
npm run dev
```

Requires `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY` in `.env.local` (see root README).
